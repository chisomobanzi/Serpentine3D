Every surface

Serpentine3D is a NURBS modeller and drafting tool for things that get built: exact curves and surfaces, drawing sheets a workshop can work from, and a command line that speaks Rhino. Free, with no account and no subscription.

Real geometry

Curves, not triangles

Surfaces here are NURBS, the same mathematics Rhino uses. A 300 mm radius is 300 mm at any zoom and on every drawing, and a pulled control point keeps the surface smooth.

Model

Your Rhino muscle memory works

Type a command and it walks you through the rest, with Rhino's names and aliases, object snaps, layers and a gumball for pushing faces and rounding edges by hand. Rhino .3dm files open with their layers, and STEP, DXF, STL, glTF and USD carry the model on to everything else.

loftsweep2revolvefilletedgebooleanunionpushpull

Draft

From model to drawing sheet

Lay out A4 to A0 sheets with live detail views at real scales, 1:25 or 1:50. Hidden-line views, dimensions, leaders, hatching, scale bars and title blocks come from the model itself, and the sheet prints straight to PDF.

Automate

Describe it. The assistant builds it.

The assistant runs the same commands you do, then looks at the viewport to check its own work, and every step can be undone. Use Claude, a ChatGPT account or an OpenAI key, or keep everything on your machine with a local, open-weight model.

Analyse

Check it before you build it

Zebra stripes and curvature colour show where surfaces meet smoothly. Draft analysis checks a mould will release, and printcheck finds open edges, thin walls and overhangs before the slicer does.

Headless

No window required

The same engine runs with no window at all. Script it in the built-in editor, batch a hundred variants from a terminal, run it in CI on a server with no display, or let any MCP client drive a live session.

Scripting guide →

make_part.py
box = doc.add(geo.make_box((0, 0, 0), 100, 100, 100), name="Crate")
doc.run("filletedge", ["Crate", "", "5"])
doc.export(args[0] if args else "crate.step")
$ serp3d-batch make_part.py crate.step
