THE DECISION

Remove the modal editor.

The drawing is already the best preview. Text content and its visual result should not compete in two separate panes.

01 / CREATE

Click, then type

The Text tool places a caret directly on paper or the current construction plane. Escape finishes; Undo removes the object.

02 / EDIT

Two doors, one value

Double-click for a caret on canvas, or edit the multiline Content field in Properties. Both update the same object immediately.

03 / MODEL

Text has a plane

Place editable lettering on the CPlane, a planar face, or the view plane. “Look at text” faces an awkward plane toward the camera while you edit.

Text tool→choose plane→click position→type on canvas→format in context→keep editable or create geometry
